## Security

1. Errbit now sanitizes V3 notice data before persistence by default. Sensitive
   values in request, session, user, and URL data are redacted recursively;
   framework-internal data is removed. See
   [Protecting Notice Data](../notice-data-privacy.md) for client-side filtering
   recommendations and server-side configuration options.
