## Breaking changes

1. Legacy Airbrake/Hoptoad XML v2 notice ingestion has been removed. The
   Airbrake v3 JSON API has been the recommended notice-ingestion API since
   2015, so this change is not expected to affect applications using the
   supported API. Applications still using XML v2 must migrate to
   `/api/v3/projects/:project_id/notices` or
   `/api/v3/projects/:project_id/create-notice`.
